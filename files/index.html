Qué hicimos paso a paso

Procedimiento

Prozedura

Procedure

01 Montaje de los robots

Escribe aquí cómo montasteis los robots: OTTO NINJA, BQ Evolution y Araña. Qué piezas imprimisteis en 3D, qué problemas tuvisteis al ensamblarlos, si algún componente llegó roto o faltaba algo.

Idatzi hemen nola muntatu dituzuen robotak: OTTO NINJA, BQ Evolution eta Araña. Zer pieza inprimatu dituzuen 3D-n, zer arazo izan dituzuen...

Write here how you assembled the robots: OTTO NINJA, BQ Evolution and Araña. Which parts you 3D-printed, what issues you had during assembly.

02 Configuración de la red WiFi segura

Explica cómo configurasteis vuestra subred: cifrado WPA2, filtrado MAC, IPs fijas. Si instalasteis portal cautivo, cómo hicisteis la auditoría, cómo montasteis el RAID y las copias de seguridad en la nube. Incluye un esquema de la red si tenéis uno.

Azaldu nola konfiguratu duzuen zuen subresarea: WPA2 zifratzea, MAC iragazketa, IP finkoak. Ate-atari zautia, ikuskaritza, RAID eta hodei babeskopiak...

Explain how you configured your subnet: WPA2 encryption, MAC filtering, fixed IPs. Captive portal, security audit, RAID and cloud backups.

03 Programación Arduino y apps

Describe cómo programasteis los robots en Arduino: el código del BQ para el siguelíneas y el circuito, el código del OTTO para las peleas, el de la Araña para la carrera. Cómo hicisteis las apps de móvil para el control Bluetooth y el control de versiones en GitHub/GitLab.

Deskribatu nola programatu dituzuen robotak Arduinon. BQ-ren kodea lerro-jarraipen eta zirkuituetarako, OTTO-rena borroketarako. App-ak eta bertsio kontrola.

Describe how you programmed the robots in Arduino: BQ code for line-following and circuit, OTTO code for fights, Araña code for the race. Mobile apps for Bluetooth control and version control on GitHub/GitLab.

04 Instalación del servidor web

Explica cómo instalasteis el servidor web en Linux: qué software usasteis (Apache, Nginx…), cómo configurasteis la IP o el dominio, cómo subisteis esta web al servidor propio y al externo.

Azaldu nola instalatu duzuen web zerbitzaria Linux-en: zer software erabili duzuen, nola konfiguratu duzuen domeinua edo IP-a, nola igo duzuen web hau.

Explain how you installed the web server on Linux: what software you used, how you configured the IP or domain, how you uploaded this site to both the own and external server.

05 Contenido multimedia e imagen de marca

Describe el proceso de creación del logotipo, la cartelería y el vídeo de presentación para YouTube. Cómo grabasteis y editasteis el vídeo, cómo añadisteis los subtítulos en inglés y la voz en off. También las redes sociales que abriste y cómo las gestionasteis.

Deskribatu logotipoaren, karteleriaren eta YouTube-ko aurkezpen-bideoaren sormen prozesua. Nola grabatu eta editatu duzuen bideoa, ingelesezko azpitituluak eta sare sozialak.

Describe the process of creating the logo, posters and the YouTube presentation video. How you recorded and edited the video, added the English subtitles and managed social media.

06 Competición: circuito, peleas y carrera

Explica cómo fueron las pruebas de competición: el circuito con el BQ, el siguelíneas, las peleas con el OTTO y la carrera con la Araña. Cómo se comportaron los robots, si ganasteis alguna prueba, qué falló y qué funcionó bien.

Azaldu nolakoak izan ziren lehiaketa-probak: BQ-ren zirkuitua, lerro-jarraipena, OTTO-ren borrokak eta Arañaren lasterketa.

Explain how the competition events went: the BQ circuit, line-following, OTTO fights and the Araña race. How the robots performed, whether you won any event, what failed and what worked.
